Backend маркетплейсу
====================

FastAPI + SQLAlchemy застосунок для простого маркетплейса: користувачі реєструються/логіняться, стають продавцями, створюють категорії та товари, оформлюють замовлення, залишають рейтинги й відгуки. Інтеграційні тести працюють з Postgres через testcontainers.

Стек
----
- Python 3.12, FastAPI, Dishka DI
- SQLAlchemy (async) + Alembic
- PostgreSQL, testcontainers для інтеграційних тестів
- Docker / Docker Compose
- pytest + httpx для тестів

Налаштування
------------
1) Створити віртуальне середовище (необов’язково, якщо використовуєте `uv`):
```bash
uv venv
uv sync
```
2) Скопіювати шаблон змінних середовища та за потреби відредагувати:
```bash
cp env.dist .env
```
3) Запустити залежності (Postgres) для локальної розробки:
```bash
docker compose up -d
```

Запуск застосунку
-----------------
```bash
uv run uvicorn marketplace.main.web_entrypoint:app --reload
```

Запуск тестів
-------------
Інтеграційні тести (потрібен Docker, testcontainers):
```bash
uv run pytest tests/integration
```
Юніт/доменні тести:
```bash
uv run pytest tests/domain
```

Структура проєкту (огляд)
-------------------------
- `src/marketplace/domain` — сутності, фабрики, інтерфейси репозиторіїв
- `src/marketplace/application` — use-case/команди/запити
- `src/marketplace/infrastructure` — таблиці/мапи БД, репозиторії, DI, запити
- `src/marketplace/presentation/web` — FastAPI роутери
- `tests/` — юніт та інтеграційні тести
- `docs/` — документація схеми та запитів

Основні можливості
------------------
- Реєстрація/автентифікація користувачів, сесійні куки
- Онбординг продавця та управління профілем
- CRUD для категорій і товарів
- Замовлення з позиціями, стани оплати/доставки
- Рейтинги та відгуки
- Аналітика: топ-рейтинг товарів, товари з низьким складом, статистика продавців/категорій
